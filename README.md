# StarsCMS 繁星CMS

**多站点内容管理与建站平台**

StarsCMS 繁星CMS 面向个人站长与多站点运营团队，提供集中建站、模板管理、内容生成与发布、团队协作及站点运营管理。

## 主要功能

- **多站点管理**：集中管理服务器与站点，支持批量建站及发布任务。
- **模板资源**：提供行业版与体育版模板，支持模板预览与资产管理。
- **内容生产**：支持 AI 辅助文章生成、内容管理与发布。
- **团队协作**：按角色分配权限，在同一团队空间内共享已获得的模板资源。
- **运营管理**：提供广告管理、搜索优化设置与蜘蛛访问统计。

## 适用场景

个人站长管理多个网站、企业维护多个品牌或业务站点，以及内容运营团队开展多站点协作。具体功能、授权范围与服务说明以官网为准。
